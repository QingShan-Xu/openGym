# 中文动作名称与描述核查

核查日期：2026-10-14。核查基线：本 fork 的 `49acbc2b`；英文目录基于上游 `5ec23d3b`。

## 结论与边界

中文覆盖不等于名称符合国内习惯，也不等于有统一官方定名。核查前，5,632 个中文名称中有 5,393 个仍与上游一致，239 个曾随中文教学做过上下文修正。上游名称存在将英文词语直接翻译而误指另一动作的情况。

本轮对全部 5,632 项完成文本来源、生成一致性、空值、版本标记、关键姿态／器械限定及明显直译风险筛查；重点术语结合英文名称、简介和完整步骤复核。**这不是 5,632 项逐条专家审定，也不把规则校验或测试通过当成运动学正确的证明。** 已确认的问题本轮修复；源文不足处保留证据和不确定性。

没有使用子代理、翻译服务、离线机翻或另调模型 API，也没有读取媒体。实际文案由当前助手结合文字上下文撰写；脚本只用于枚举、保存已审定的词语替换、更新版本标记、调整模板类型标签与生成数据。

## 典型修正

| 英文源名称 | 原中文名称 | 修正／原因 |
|---|---|---|
| archer push up | 弓步俯卧撑 | 射箭式俯卧撑；另可搜“弓箭手式”。一臂屈肘、另一臂向外伸，不是弓步组合 |
| archer pull up | 弓步引体向上 | 射箭式引体向上；动作含单侧偏重和伸直支撑臂，不含弓步 |
| air bike | 空气自行车 | 此 ID 是自行车卷腹；依据仰卧、对侧肘膝交替靠近的步骤，不是风阻单车 |
| assault bike run | 战斗单车冲刺 | 风阻单车冲刺；与自行车卷腹分开 |
| skull crusher | 颅骨粉碎者／颅骨推举 | 仰卧臂屈伸；屈肘将杠铃降向额头再伸肘，保留上下斜和握距限定 |
| muscle up | 双杠上推／肌肉上拉 | 单杠双力臂；借力、负重与竖杆变式分别命名 |
| sissy squat | 西西里深蹲 | 西西深蹲；不把英文 Sissy 错当为 Sicily |
| triceps kickback | 三头肌后踢 | 臂后伸；这是伸肘练习，不能写成踢腿 |
| wind sprints | 风中冲刺 | 间歇冲刺跑；短时冲刺后休息，与有风无关 |
| arm slingers hanging legs | 悬垂甩臂 | 悬垂屈膝／直腿举腿；源步骤没有甩臂 |
| teaser | 挑战式 | 普拉提V字起身（Teaser）；说明其卷起、抬腿与V字平衡 |
| power clean / power snatch | 力量翻／力量抓举 | 高翻／高抓；浅蹲接杠与下蹲翻、实力翻／抓举区分 |
| clean and jerk | 高翻挺举 | 完整挺举；不把全部 clean 自动当成浅蹲高翻 |
| muscle clean / muscle snatch | 肌肉高翻／肌肉抓举 | 实力翻／实力抓举；源步骤明确不再次屈膝接杠 |
| plate loaded | 插片式 | 挂片式；独立杠铃片加载与插销选择配重不是同一结构 |
| sled leg press | 雪橇腿举 | 滑轨腿举；腿举机滑轨与地面推行的训练雪橇分开 |
| rear delt | 后三角肌 | 三角肌后束；另可用“后束”“反飞鸟”等合适别名搜索 |
| larsen press | 拉森推举 | 拉森卧推；源步骤明确平凳卧推、双脚离地 |

同一动作确有不同叫法时，不强行宣布唯一正确名称。例如“牧师凳弯举／斯科特弯举／托臂弯举”“地雷杆／地雷管”“反向飞鸟／反飞鸟”可搜索到相应动作，并保留器械和姿态限制。错误旧译名不作为正确别名保留。

## 描述为何要单独核查

核查前有 5,581 条简介采用“名称＋训练部位＋器械＋肌群”的模板，并不是英文简介的逐句翻译。本轮纠正拉伸、活动度、瑜伽、普拉提等类型用语，也不再说“主要锻炼脊柱”。对于明确误译和常见动作，结合英文简介与步骤写出动作本身。

目前仍有 5,491 条元数据摘要。它们可用于基本分类和肌群识别，**不能当作英文简介已完整校译的证明**；后续逐条具体化仍应读取该动作完整源文本，不做词语替换式“翻译”。

## 源文本疑点：不擅自编造差异或步骤

| ID | 问题与处理 |
|---|---|
| 0631、3286、1401 | 名称／简介描述双力臂，但源步骤缺少完整过杠撑起转换。修正名称与动作简介，未把不完整步骤宣称已验证 |
| 3297、3298、3301 | 后水平、分腿俄式挺身、蛙式支撑的步骤对转换或支撑方式不完整。采用可支持的动作名，不新增进入方法 |
| 1751 | pin presses 简介指限位架起始推举，步骤混有站姿与卧推叙述。改为中性的“杠铃限位架推举”，不认定站／卧姿 |
| 1733 | 简介指上斜双臂肱三头肌伸展，步骤没有清楚写出屈肘过程。名称按简介命名，保留步骤冲突记录 |
| 3183、5190、0295、5101 | 源步骤未明确接杠／接铃深度，不自动将 clean 都定为浅蹲高翻或全蹲下蹲翻 |
| 0648 | power clean 简介说浅蹲接杠，旧步骤只写 front squat position，没有深度。高翻名称依据英文动作名和简介，步骤未改 |
| 0972 | 标为带阻力的自行车卷腹，但旧步骤没有说明弹力带如何设置。本轮不补造固定方法 |
| 0003／6211、2838／5250、2420／4699、1575／3616 | 英文目录含动作文本近似的独立 ID。标准化后可能同名；不凭空发明不同姿势来“去重”，也不修改历史 ID |
